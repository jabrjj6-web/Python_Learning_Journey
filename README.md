رحلتي في تعلم أساسيات لغة بايثون 🐍🚀

مرحباً بكم في مستودعي الخاص! هذا المشروع يوثق مجهودي وشغفي في تعلم البرمجة من الصفر. 

قمت بمتابعة وتطبيق كورس مكثف لأساسيات لغة بايثون (مدته 300 دقيقة)، وقمت بكتابة وتجربة أكثر من 40 كوداً برمجياً وتطبيقاً عملياً بنفسي.

### 📁 محتويات المستودع:
* الدوال (Functions): تطبيقات متقدمة على بناء الدوال وتمرير البيانات واستخدام الـ return.
* الجمل الشرطية (If Conditions): بناء مشروع حاسبة متكاملة يتعامل مع الشروط والعمليات الحسابية المختلفة.
* حلقات التكرار (Loops): فهم وتطبيق جمل التكرار لمعالجة النصوص والبيانات.
* المتغيرات والمدخلات: التعامل مع الـ input وتحويل أنواع البيانات مثل float.
